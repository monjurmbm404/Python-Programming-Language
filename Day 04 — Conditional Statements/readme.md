# 🐍 Python Programming – Day 04: Conditional Statements

---

## 📌 Overview

In this chapter, you will learn about **Conditional Statements in Python**.

Conditional statements help your program make **decisions based on conditions**.

They are like real-life choices:

- If it is raining → take an umbrella ☔
- If you are 18+ → you can vote 🗳️
- Otherwise → do something else

---

# 🔹 01. if Statement

## 📁 01_if_statement.py

### 📘 What you learn:

- Runs code only when condition is **True**

### 🧠 Example:

```python id="pyif1"
age = 18

if age >= 18:
    print("You are eligible to vote")

print("Program ended")
```

---

# 🔹 02. if-else Statement

## 📁 02_if_else_statement.py

### 📘 What you learn:

- One block runs if condition is True
- Otherwise `else` runs

### 🧠 Example:

```python id="pyif2"
number = 10

if number % 2 == 0:
    print("Even number")
else:
    print("Odd number")
```

---

# 🔹 03. if-elif-else Ladder

## 📁 03_if_elif_else.py

### 📘 What you learn:

Used when you have **multiple conditions**

### 🧠 Example:

```python id="pyif3"
marks = 85

if marks >= 90:
    print("Grade A+")
elif marks >= 80:
    print("Grade A")
elif marks >= 70:
    print("Grade B")
else:
    print("Fail")
```

---

# 🔹 04. Nested Conditions

## 📁 04_nested_conditions.py

### 📘 What you learn:

- One `if` inside another `if`
- Used for complex logic

### 🧠 Example:

```python id="pyif4"
age = 20
has_id = True

if age >= 18:
    if has_id:
        print("Allowed to enter")
    else:
        print("ID required")
else:
    print("Not allowed")
```

---

# 🔹 05. Short-hand if (Ternary Style)

## 📁 05_short_hand_if.py

### 📘 What you learn:

- One-line if-else statement

### 🧠 Example:

```python id="pyif5"
age = 22

result = "Adult" if age >= 18 else "Minor"
print(result)
```
