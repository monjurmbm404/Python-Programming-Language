# 🐍 Python Programming – Day 03: Operators

---

## 📌 Overview

In this chapter, you will learn about **Operators in Python**.
Operators are special symbols that are used to perform operations on variables and values.

They help us:

- Do calculations
- Compare values
- Make decisions
- Work with memory and conditions

---

# ➗ 01. Arithmetic Operators

## 📁 01_arithmetic_operators.py

### 📘 What you learn:

Arithmetic operators are used for **mathematical calculations**.

| Operator | Meaning             |
| -------- | ------------------- |
| +        | Addition            |
| -        | Subtraction         |
| \*       | Multiplication      |
| /        | Division            |
| %        | Modulus (remainder) |
| \*\*     | Exponent (power)    |
| //       | Floor division      |

### 🧠 Example Use:

```python
a = 10
b = 3

print(a + b)   # 13
print(a / b)   # 3.33
print(a ** b)  # 1000
```

---

# 🧾 02. Assignment Operators

## 📁 02_assignment_operators.py

### 📘 What you learn:

Assignment operators are used to **assign and update values**.

| Operator | Meaning           |
| -------- | ----------------- |
| =        | Assign            |
| +=       | Add & assign      |
| -=       | Subtract & assign |
| \*=      | Multiply & assign |
| /=       | Divide & assign   |

### 🧠 Example:

```python
x = 10
x += 5   # x = x + 5 → 15
```

---

# ⚖️ 03. Relational (Comparison) Operators

## 📁 03_relational_operators.py

### 📘 What you learn:

Used to **compare values** and return True/False.

| Operator | Meaning          |
| -------- | ---------------- |
| ==       | Equal            |
| !=       | Not equal        |
| >        | Greater than     |
| <        | Less than        |
| >=       | Greater or equal |
| <=       | Less or equal    |

### 🧠 Example:

```python
a = 10
b = 20

print(a > b)   # False
print(a == b)  # False
```

---

# 🔗 04. Logical Operators

## 📁 04_logical_operators.py

### 📘 What you learn:

Used to combine multiple conditions.

| Operator | Meaning           |
| -------- | ----------------- |
| and      | Both must be True |
| or       | One must be True  |
| not      | Reverse result    |

### 🧠 Example:

```python
a = True
b = False

print(a and b)  # False
print(a or b)   # True
print(not a)    # False
```

---

# 📦 05. Membership Operators

## 📁 05_membership_operators.py

### 📘 What you learn:

Check if a value exists in a sequence.

| Operator | Meaning        |
| -------- | -------------- |
| in       | Exists         |
| not in   | Does not exist |

### 🧠 Example:

```python
text = "Python"

print("P" in text)     # True
print("Java" in text)   # False
```

---

# 🧠 06. Identity Operators

## 📁 06_identity_operators.py

### 📘 What you learn:

Check if two variables refer to the **same memory object**.

| Operator | Meaning          |
| -------- | ---------------- |
| is       | Same object      |
| is not   | Different object |

### 🧠 Example:

```python
a = [1, 2]
b = [1, 2]

print(a is b)  # False
```

---

# 🔢 07. Bitwise Operators

## 📁 07_bitwise_operators.py

### 📘 What you learn:

Works at **binary level (0 and 1)**.

| Operator | Meaning     |     |
| -------- | ----------- | --- |
| &        | AND         |     |
|          | OR          |     |
| ^        | XOR         |     |
| ~        | NOT         |     |
| <<       | Left shift  |     |
| >>       | Right shift |     |

### 🧠 Example:

```python
a = 5
b = 3

print(a & b)
print(a | b)
```

---

# ❓ 08. Ternary Operator

## 📁 08_ternary_operator.py

### 📘 What you learn:

Short way to write **if-else condition**.

### 🧠 Syntax:

```python
value_if_true if condition else value_if_false
```

### 🧠 Example:

```python
a = 10
b = 20

result = "A is greater" if a > b else "B is greater"
print(result)
```
