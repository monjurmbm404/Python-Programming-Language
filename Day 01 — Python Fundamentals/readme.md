## ⚙️ 2. Installation & Setup

To start coding in Python:

1. Download Python from:
   👉 [https://www.python.org](https://www.python.org)

2. Install Python
   ✅ Important: Check **“Add Python to PATH”**

3. Verify installation:

```bash
python --version
```

4. Install packages (optional):

```bash
pip install package_name
```

---

## ▶️ 3. Running Python

You can run Python in different ways:

### 🔹 CLI (Command Line)

```bash
python filename.py
```

### 🔹 Interactive Mode

```bash
python
>>> print("Hello")
```

### 🔹 IDE (Recommended for Beginners)

- VS Code
- PyCharm
- Jupyter Notebook

💡 Python runs **line by line**, not like compiled languages.

## 👋 4. Your First Python Program

```python
print("Hello, World!")
```

🖥️ Output:

```
Hello, World!
```

🎉 Congratulations! You just wrote your first Python program!

---

## 📏 5. Syntax & Indentation

Python uses **indentation (spaces)** instead of `{}`.

```python
if True:
    print("This is correct")
```

❌ Wrong (no indentation):

```python
# if True:
# print("Error!")
```

💡 Always use **4 spaces** for indentation.

---

## 💬 6. Comments in Python

Comments help explain your code.

### 🔹 Single-line comment

```python
# This is a comment
```

### 🔹 Multi-line comment

```python
"""
This is a multi-line comment
"""
```

---

## 🖨️ 7. Output using `print()`

The `print()` function displays output.

```python
print("Hello")
print("Python")
```

### Multiple values

```python
print("Name:", "Monjur", "Age:", 22)
```

### Custom separator

```python
print("2026", "04", "12", sep="-")
```

### Custom ending

```python
print("Hello", end=" ")
print("World")
```

🖥️ Output:

```
Hello World
```

---

## 🔤 8. Escape Sequences

Special characters used inside strings:

| Escape | Meaning      |
| ------ | ------------ |
| `\n`   | New Line     |
| `\t`   | Tab Space    |
| `\"`   | Double Quote |
| `\\`   | Backslash    |

### Example:

```python
print("Hello\nPython")
print("Name:\tMonjur")
print("\"Python Programming\"")
print("C:\\Users\\Python")
```
